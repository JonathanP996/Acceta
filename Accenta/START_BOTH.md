# Starting Accenta - Full Stack

## Quick Start

### Terminal 1 - Backend
```bash
cd Accenta/backend
source ../venv/bin/activate
uvicorn app:app --reload
```
Backend: http://localhost:8000

### Terminal 2 - Frontend
```bash
cd Accenta/frontend
npm start
```
Frontend: http://localhost:3000
